# Time and duration

## Guidance

- Absolute timestamps on resources **must** use RFC 3339 strings on the wire.
- Standard resource timestamps **must** be named:
  - `created_timestamp` (required on resources that track create time; read-only)
  - `updated_timestamp` (optional/nullable pointer when never updated; read-only)
- Do **not** use Google AIP names `create_time` / `update_time` on this public
  surface.
- Durations that are configured limits **should** use explicit millisecond
  integer fields with a `_milliseconds` suffix (for example
  `ring_time_limit_milliseconds`, `delay_milliseconds`).
- Civil dates without a timezone **should** use a `_date` suffix if introduced.
