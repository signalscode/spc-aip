# Standard methods: Get

## Guidance

- Get **must** use `GET`.
- Path **must** address one resource by id:
  `/beta/{collection}/{id}` (or a nested instance path).
- Get **must not** take a request body.
- The response body **must** be the resource object itself (no envelope
  wrapper such as `{ "data": ... }` unless a resource explicitly documents
  one).
- Unknown ids **must** map to HTTP 404 with an
  `application/problem+json` body ([AIP-193](./0193.md)).
- Ids of resources that were Deleted **must** also map to `404` with the same
  shape; clients **must not** be able to distinguish “never existed” from
  “deleted” ([AIP-135](./0135.md)).

### Example

```http
GET /beta/books/BRAC_HS4_ug
```

```http
HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": "BRAC_HS4_ug",
  "name": "Les Misérables",
  "created_timestamp": "2021-01-01T00:00:00Z"
}
```
