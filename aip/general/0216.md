# States

## Guidance

- Lifecycle or status fields **should** be string enums (`snake_case` values).
- Mutating state **should** use dedicated custom methods when the transition is
  an action (`:pause`, `:resume`, `:cancel`) rather than a free-form PATCH of a
  status field.
- Status fields on resources **may** be read-only when only the server or
  custom methods may change them.
