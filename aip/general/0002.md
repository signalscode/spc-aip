# AIP Numbering

## Guidance

- General guidance uses AIP numbers in the traditional Google ranges kept by
  this fork (for example 121–136 for resources/methods).
- Organization-specific guidance, if added later, **must** use the 9000–9999
  block reserved for private AIPs.
- Do not reintroduce deleted Google area blocks (Cloud, Firebase, Auth,
  client libraries, AoG) unless product needs change.
