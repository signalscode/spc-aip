# Filtering

## Guidance

- Simple filters **should** be explicit query parameters on List methods.
- Filter parameters **must** use `snake_case` names.
- Do not require a single unstructured `filter` string expression language
  unless a resource explicitly adopts one.
- Changing filter parameters while paginating is allowed; page contents and any
  total count reflect the filtered set.
- Pagination field names follow [AIP-158](./0158.md) (pagination model is
  undecided for `/vN`; examples below use today’s `/beta` `skip` / `limit`).

### Example

```http
GET /beta/books?author_id=author_91c0e4ab22&skip=0&limit=20
```

```json
{
  "items": [{ "id": "book_7f3a9c2e1d0b", "name": "Les Misérables", "author_id": "author_91c0e4ab22" }],
  "total": 3,
  "skip": 0,
  "limit": 20
}
```
