# Standard methods: List

## Guidance

- List **must** use `GET` on the collection path: `/beta/{collection}`.
- List **must** support [pagination](./0158.md). Until the pagination-model
  TODO in AIP-158 is resolved, document `skip` / `limit` / `total` as today’s
  `/beta` shape (not a locked forever choice for `/vN`).
- List **may** accept additional filter query parameters (see
  [AIP-160](./0160.md)).
- List **must not** take a request body.
- Deleted resources **must not** appear in List. There is no `show_deleted`
  flag. Delete is final on the public contract; there is no restore
  ([AIP-135](./0135.md)).

### Example

```http
GET /beta/books?skip=0&limit=20
```

```json
{
  "items": [
    { "id": "AAIQBQAAAAAAAAPp", "name": "Les Misérables" },
    { "id": "AAIQBQAAAAAAAAPq", "name": "The Odyssey" }
  ],
  "total": 100,
  "skip": 0,
  "limit": 20
}
```
