# Resource types

Each public resource has a named schema in the OpenAPI document and a
collection path derived from that noun.

## Guidance

- Resource type names **must** be singular PascalCase (`Book`, `PhoneNumber`).
- Collection path segments **must** be the plural kebab-case form of the noun
  (`books`, `phone-numbers`).
- OpenAPI tags **should** be human-readable titles (`Books`, `Phone Numbers`).
- `operationId` values **must** be `{Version}_{camelAction}` and human Names
  `{Version}{PascalAction}` (for example `Beta_getBook` / `BetaGetBook`).
- Do not invent Google-style type URLs (`library.googleapis.com/Book`) for the
  public HTTP surface.

### Example

```http
GET /beta/books/AUIAE-DUXA
```

```yaml
# OpenAPI (excerpt)
tags:
  - name: Books
paths:
  /beta/books/{id}:
    get:
      operationId: Beta_getBook
      tags: [Books]
```
