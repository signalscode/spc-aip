# Enumerations and unions

Closed sets of string values and discriminated unions are first-class on the
public wire.

## Guidance

### String enums

- Enumerations **must** be JSON strings.
- Enum values **must** use `snake_case` (`inbound_phone`, `hang_up`).
- OpenAPI **must** list allowed values under `enum`.

```json
{ "channel_kind": "inbound_phone" }
```

```yaml
ChannelKind:
  type: string
  enum: [inbound_phone, outbound_phone, chat]
```

### Discriminated unions

- Variant objects **must** include a `kind` discriminator field.
- Each variant fixes `kind` to one enum value and carries only that variant's
  fields.
- OpenAPI **must** model the union as `oneOf` with a `discriminator` on `kind`.

```json
{
  "call_initiation": {
    "kind": "static",
    "begin_message": "Thanks for calling.",
    "delay_ms": 1000
  }
}
```

```json
{
  "call_initiation": {
    "kind": "user_started",
    "delay_ms": 1000
  }
}
```

```yaml
CallInitiation:
  oneOf:
    - $ref: '#/components/schemas/CallInitiationStatic'
    - $ref: '#/components/schemas/CallInitiationUserStarted'
  discriminator:
    propertyName: kind
    mapping:
      static: '#/components/schemas/CallInitiationStatic'
      user_started: '#/components/schemas/CallInitiationUserStarted'
CallInitiationStatic:
  type: object
  required: [kind, begin_message]
  properties:
    kind:
      type: string
      enum: [static]
    begin_message:
      type: string
    delay_ms:
      type: integer
      format: int64
```
