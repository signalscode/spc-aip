# Standard fields

Common fields shared across resources.

## Guidance

| Field | Requirement |
| ----- | ----------- |
| `id` | Stable `{type}_{object}` UID string; read-only; required on resources ([AIP-122](./0122.md)) |
| `name` | Display name when the resource has one |
| `created_timestamp` | Create time when tracked; read-only |
| `updated_timestamp` | Last update time when tracked; read-only; may be null |
| `is_active` | Optional boolean enablement when a resource has an on/off state |

- Public `id` / `*_id` values **must** be `{type}_{object}` UID strings
  ([AIP-122](./0122.md)). Do **not** expose sequential integers as public
  identifiers. OpenAPI **should** document them as strings with
  `minLength` 11, `maxLength` 18, and pattern
  `^[A-Za-z0-9_-]+_[A-Za-z0-9_-]+$`.
- Do **not** require Google AIP fields `name` (as resource path), `etag`,
  `uid`, `delete_time`, or `annotations` unless a specific resource documents
  them.
- Parent linkage for nested resources is expressed in the URL path and/or
  explicit `*_id` fields (for example `shelf_id`), not a universal `parent`
  string.
