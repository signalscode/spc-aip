# Sensitive fields

## Guidance

- Secrets, credentials, and private keys **must not** appear in public resource
  responses.
- Public HTTP authentication uses API keys via the `X-Api-Key` request header;
  do not return key material in resource bodies.
- PII fields **should** be limited to what the product requires and documented
  clearly.

### Example

```http
GET /beta/books/AAIQBQAAAAAAAAPp
X-Api-Key: <redacted>
```

```json
{
  "id": "AAIQBQAAAAAAAAPp",
  "name": "Les Misérables"
}
```

Incorrect (never return secrets):

```json
{
  "id": "AAIQBQAAAAAAAAPp",
  "api_key": "sk_live_..."
}
```
