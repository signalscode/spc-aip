# Stability levels

Endpoint stability is determined by the **URL path prefix**, not by document
filenames, OpenAPI `info.version`, or visibility flags.

## Guidance

- The first path segment **must** be a version channel: `beta`, `v1`, `v2`, …
  (and `alpha` when used).
- That prefix **determines** the stability of every endpoint under it:

  | Path prefix | Stability |
  | ----------- | --------- |
  | `/alpha/...` | Experimental; may break without a new channel |
  | `/beta/...` | Preview; may break without a new channel |
  | `/v1/...`, `/v2/...`, … | Stable for that major version; breaking changes require a new prefix |

- All endpoints that share a prefix share that prefix's stability rules. Do not
  assign a different stability class to an individual operation under the same
  prefix.
- Visibility flags (for example `x-hidden`) only control whether an operation
  appears in the public OpenAPI snapshot. They **do not** change stability:
  a hidden `/v1/...` operation is still under the stable `v1` channel; a public
  `/beta/...` operation is still preview.

### Example

```http
GET /beta/books/BRAC_HS4_ug          # preview stability
GET /v1/books/BRAC_HS4_ug            # stable v1 compatibility
GET /v2/books/BRAC_HS4_ug            # stable v2 compatibility
```

```yaml
paths:
  /beta/books/{id}:
    get:
      operationId: Beta_getBook
  /v1/books/{id}:
    get:
      operationId: V1_getBook
```
