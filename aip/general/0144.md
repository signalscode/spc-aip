# Repeated fields

## Guidance

- JSON arrays represent repeated fields.
- Field names **must** be plural.
- On Update, JSON `null` clears the array. `null` and `[]` are equivalent.
  Omitting the field leaves the current array unchanged
  ([AIP-134](./0134.md)).
- On Create and Replace, empty arrays and omitted arrays **should** follow the
  field's documented nullability. Prefer documenting whether `[]` and omission
  are equivalent.
- Do not use parallel singular `foo` + `foos` fields for the same concept.

### Example

```json
{
  "id": "AUIAE-DUXA",
  "labels": ["fiction", "classic"],
  "agent_swaps": [
    {
      "tool_name": "transfer_to_sales",
      "target_book_id": "AUIAE-GKVA"
    }
  ]
}
```
