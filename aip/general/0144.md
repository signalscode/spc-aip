# Repeated fields

## Guidance

- JSON arrays represent repeated fields.
- Field names **must** be plural.
- Empty arrays and omitted arrays **should** follow the resource's documented
  nullability rules. Prefer documenting whether `[]` and omission are
  equivalent.
- Do not use parallel singular `foo` + `foos` fields for the same concept.

### Example

```json
{
  "id": "AUIAE-DUXA",
  "labels": ["fiction", "classic"],
  "agent_swaps": [
    {
      "tool_name": "transfer_to_sales",
      "target_book_id": "AUIAE-GKVA"
    }
  ]
}
```
