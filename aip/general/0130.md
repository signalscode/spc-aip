# Methods

APIs expose standard methods plus custom methods when needed.

## Guidance

- Prefer the standard methods in AIPs 131–135.
- Use [custom methods](./0136.md) for actions that are not CRUD (`:clone`,
  `:pause`, `:generate-summary`, `:cancel`, `:download`).
- Use [Replace (PUT)](./0134.md) for singleton upsert and association attach.
- Method naming:
  - OpenAPI `operationId`: `{Version}_{camelAction}` (example `Beta_cloneBook`)
  - Display name: `{Version}{PascalAction}` (example `BetaCloneBook`)

### Example

```http
POST /beta/books/BRAC_HS4_ug:clone
```

```yaml
paths:
  /beta/books/{id}:clone:
    post:
      operationId: Beta_cloneBook
      summary: Clone a book
```
