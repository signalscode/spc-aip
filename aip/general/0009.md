# Glossary

| Term | Meaning in this fork |
| ---- | -------------------- |
| Resource | A public noun with an opaque string `id` and JSON schema |
| Collection | Plural kebab-case path under a version prefix |
| Version prefix | First path segment (`beta`, `v1`, `v2`, …); determines stability |
| Singleton | Parent-scoped settings path without a child id |
| Replace | `PUT` create-or-replace for singletons/associations (not undelete; Delete is final) |
| Delete | Final on the public contract: Get → 404, no List, no restore ([AIP-135](./0135.md)) |
| Update | `PATCH` partial update without field masks (field clear/null rules undecided — [TODO.md](../../TODO.md)) |
| Custom method | Colon-delimited `kebab-case` verb such as `:clone` or `:generate-summary` (not a path segment) |
| Hidden | Operation omitted from the public OpenAPI snapshot (not a stability class) |
| Problem | RFC 9457 error body (`application/problem+json`); see [AIP-193](./0193.md) |
| Implementer | A service that publishes HTTP/OpenAPI contracts conforming to these AIPs |
