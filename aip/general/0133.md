# Standard methods: Create

## Guidance

- Create **must** use `POST` on the collection path: `/beta/{collection}`.
- Successful Create **must** return **201 Created**.
- The request body **must** be a dedicated create request object (flat JSON),
  not a nested `{ "book": { ... } }` envelope.
- The server assigns `id`. Clients **must not** supply `id` on create.
- The response body **must** be the created resource.

### Example

```http
POST /beta/books
Content-Type: application/json

{ "name": "Les Misérables", "title": "A Novel" }
```

```http
HTTP/1.1 201 Created
Content-Type: application/json

{
  "id": "AAIQBQAAAAAAAAPp",
  "name": "Les Misérables",
  "title": "A Novel",
  "created_timestamp": "2021-01-01T00:00:00Z",
  "updated_timestamp": null
}
```
