# Field names

JSON field names on the public wire are `snake_case`.

## Guidance

- JSON property names **must** be `lower_snake_case`.
- Repeated fields **must** be plural (`items`, `agent_swaps`).
- Boolean fields **may** use an `is_` prefix when that matches product language
  (`is_active`).
- Prefer concise nouns; avoid prepositional names (`error_reason`, not
  `reason_for_error`).
- Human-readable labels use `name` (display name) unless a resource needs both
  a formal `title` and a `name`.
- Foreign keys use `*_id` suffixes (`publisher_id`, `shelf_id`) and are
  opaque strings, same as `id` ([AIP-122](./0122.md)).
- Do **not** emit camelCase JSON (`createdTimestamp`, `pageSize`) on this
  public HTTP surface.

### Example

```json
{
  "id": "book_7f3a9c2e1d0b",
  "name": "Main line",
  "is_active": true,
  "area_code": "415",
  "publisher_id": "publisher_42aa",
  "created_timestamp": "2021-01-01T00:00:00Z"
}
```
