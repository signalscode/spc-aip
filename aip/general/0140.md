# Field names

JSON field names on the public wire are `snake_case`.

## Guidance

- JSON property names **must** be `lower_snake_case`.
- Repeated fields **must** be plural (`items`, `agent_swaps`).
- Boolean fields **may** use an `is_` prefix when that matches product language
  (`is_active`).
- Prefer concise nouns; avoid prepositional names (`error_reason`, not
  `reason_for_error`).
- Human-readable labels use `name` (display name) unless a resource needs both
  a formal `title` and a `name`.
- Foreign keys use `*_id` suffixes (`publisher_id`, `shelf_id`) and are
  `{type}-{object}` UID strings, same as `id` ([AIP-122](./0122.md)).
- Do **not** emit camelCase JSON (`createdTimestamp`, `pageSize`) on this
  public HTTP surface.

### Abbreviations

For well-known abbreviations among software developers, **use the abbreviation**
in field names instead of the full spelling (aligned with
[google.aip.dev/140](https://google.aip.dev/140)):

| Prefer | Instead of |
| ------ | ---------- |
| `config` | `configuration` |
| `id` | `identifier` |
| `info` | `information` |
| `spec` | `specification` |
| `stats` | `statistics` |

Unit abbreviations for quantity fields are in [AIP-141](./0141.md) (for example
`delay_ms`, not `delay_milliseconds`).

### Example

```json
{
  "id": "AUIAE-DUXA",
  "name": "Main line",
  "is_active": true,
  "area_code": "415",
  "publisher_id": "AQIAE-DUXA",
  "created_timestamp": "2021-01-01T00:00:00Z"
}
```
