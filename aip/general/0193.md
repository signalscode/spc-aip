# Errors

The public HTTP error contract is **RFC 9457 Problem Details** served as
`application/problem+json`. Do not use `google.rpc.Status` or ad-hoc JSON error
objects.

## Guidance

- Failed requests **must** return an HTTP error status with
  `Content-Type: application/problem+json`.
- The problem body **must** include:

  | Field | Type | Required | Meaning |
  | ----- | ---- | -------- | ------- |
  | `title` | string | yes | Short summary of the HTTP problem. Stable for that status. |
  | `status` | number | yes | HTTP status code. Same number as the response status. |
  | `detail` | string | yes | Human-readable explanation of this occurrence. |

- There is **no** `code` field. Clients **must** key off the HTTP status and
  the body's `status`, not free-text `detail`.
- The problem body **may** include:
  - `type` — URI identifying the problem type (RFC 9457). Omitted responses
    use the default `about:blank`.
  - `instance` — URI identifying this occurrence.
  - `errors` — field-level issues. Omit it when the failure is not tied to
    specific fields. Each item has:

    | Field | Type | Meaning |
    | ----- | ---- | ------- |
    | `message` | string | What is wrong at that location |
    | `location` | string | Where it failed, for example `body.outbound_cloud_employee_id` or `query.limit` |
    | `value` | any | The rejected value at that location |

- Unknown resources **must** map to `404` with title `Not Found`.
- Unauthenticated requests **should** map to `401`. Unauthorized requests
  **should** map to `403`.
- Request-body and parameter validation failures **must** map to `422` with
  title `Unprocessable Entity`, detail `validation failed`, and an `errors`
  array.
- Do **not** return `google.rpc.Status` envelopes (`error.status`, `ErrorInfo`).
- Avoid returning partial success payloads for ordinary unary methods.
- OpenAPI **must** document `ErrorModel` as the error response body for
  4xx/5xx responses.

### Example

```http
HTTP/1.1 404 Not Found
Content-Type: application/problem+json

{
  "title": "Not Found",
  "status": 404,
  "detail": "Book AUIAE-DUXA was not found."
}
```

```http
HTTP/1.1 422 Unprocessable Entity
Content-Type: application/problem+json

{
  "title": "Unprocessable Entity",
  "status": 422,
  "detail": "validation failed",
  "errors": [
    {
      "message": "expected integer",
      "location": "body.outbound_cloud_employee_id",
      "value": "177"
    }
  ]
}
```

```yaml
# OpenAPI (excerpt)
components:
  schemas:
    ErrorDetail:
      type: object
      additionalProperties: false
      properties:
        message:
          type: string
          description: Error message text
        location:
          type: string
          description: Where the error occurred, e.g. 'body.items[3].tags' or 'path.thing-id'
        value:
          description: The value at the given location
    ErrorModel:
      type: object
      additionalProperties: false
      properties:
        title:
          type: string
          example: Unprocessable Entity
        status:
          type: integer
          format: int64
          example: 422
        detail:
          type: string
          example: validation failed
        type:
          type: string
          format: uri
          default: about:blank
        instance:
          type: string
          format: uri
        errors:
          type: array
          items:
            $ref: '#/components/schemas/ErrorDetail'
```
