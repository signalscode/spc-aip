# Errors

The public HTTP error contract is **RFC 9457 Problem Details** served as
`application/problem+json`. Do not use `google.rpc.Status` or ad-hoc JSON error
objects.

## Guidance

- Failed requests **must** return an HTTP error status with
  `Content-Type: application/problem+json`.
- The problem body **must** include:

  | Field | Type | Required | Meaning |
  | ----- | ---- | -------- | ------- |
  | `title` | string | yes | Short, stable summary |
  | `status` | number | yes | HTTP status code (same as the response status) |
  | `detail` | string | yes | Human-readable explanation |
  | `code` | string | yes | Stable machine-readable error code (`snake_case`) |

- The problem body **may** include:
  - `type` — URI identifying the problem type (RFC 9457)
  - `instance` — URI identifying this occurrence
  - `errors` — array of field-level issues for validation failures, each with
    `location` (for example `query.limit` or `body.name`) and `message`
- Clients **must** key off `status` and `code`, not free-text `detail`.
- Unknown resources **should** map to `404` / `code: not_found`.
- Unauthenticated / unauthorized requests **should** map to `401` / `403` with
  stable codes (for example `unauthenticated`, `permission_denied`).
- Invalid arguments **should** map to `400` / `code: invalid_argument`.
- Do **not** return `google.rpc.Status` envelopes (`error.status`, `ErrorInfo`).
- Avoid returning partial success payloads for ordinary unary methods.
- OpenAPI **should** document this problem schema as the default error response
  body for 4xx/5xx responses.

### Example

```http
HTTP/1.1 404 Not Found
Content-Type: application/problem+json

{
  "title": "Not Found",
  "status": 404,
  "detail": "Book book_7f3a9c2e1d0b was not found.",
  "code": "not_found"
}
```

```http
HTTP/1.1 400 Bad Request
Content-Type: application/problem+json

{
  "title": "Bad Request",
  "status": 400,
  "detail": "limit must be between 1 and 100.",
  "code": "invalid_argument",
  "errors": [
    {
      "location": "query.limit",
      "message": "must be <= 100"
    }
  ]
}
```

```yaml
# OpenAPI (excerpt)
components:
  schemas:
    Problem:
      type: object
      required: [title, status, detail, code]
      properties:
        title:
          type: string
          example: Not Found
        status:
          type: integer
          example: 404
        detail:
          type: string
        code:
          type: string
          example: not_found
        type:
          type: string
          format: uri
        instance:
          type: string
          format: uri
        errors:
          type: array
          items:
            type: object
            required: [location, message]
            properties:
              location:
                type: string
                example: query.limit
              message:
                type: string
```
